# P10 通讯录实体 Android RC 验收

本清单只验收微信体验版 `0.1.0-p9.20260827.33` 的原生通讯录；当前生产 `organization=true`，不提交审核或正式发布。所有号码和组织名称以当前体验版实际显示为准，不截图、不复制或外传真实号码。

## 进入与能力状态

1. 使用已绑定的管理员或普通成员账号进入当前群组，在工作台 More 打开“院内通讯录”。访客账号不得显示该入口。
2. 当前生产能力为 `organization=true`：成员页面可进入并按服务端权限读取目录；访客账号不得通过切换入口或请求直接获得目录。
3. 在关闭能力的隔离环境复核 `organization=false`：页面显示“通讯录暂未开放”，不出现加载中的真实号码，也不产生通讯录请求；返回工作台后再次进入，关闭态文案和导航不闪烁。

## 院内模式（能力开启的隔离环境）

1. 以组织能力开启的隔离环境复核：页面先显示 facets，再保持空态，只有输入关键词或选择筛选条件后才发起列表查询。
2. 依次选择院区、片区、楼宇、楼层、科室、单元、类型；每次选择都保留其他已选条件，结果摘要与列表同步更新。
3. 输入科室/姓名/号码关键词并确认搜索；清空关键词且无筛选时回到空态，不拉取全量目录。
4. 滚动到“加载更多”，确认 cursor 请求追加记录、不重复首屏、不丢失筛选条件。
5. 点击完整手机/座机号码，确认只触发一次拨号；只有内线号的联系人显示为只读文本，不触发拨号。

## 员工模式与权限

1. 切换“员工”标签，确认请求 employee-directory 路径，筛选标签变为“组织根、一级组织、二级组织、三级组织、四级组织、五级组织、类型”。
2. 普通成员与管理员分别复核可见条目差异；不得通过切换模式看到超出服务端权限的条目或号码。
3. 进入/退出页面、切换院内/员工和重复点击搜索后，不出现旧模式结果、旧号码或重复请求提示。

## 通过条件
