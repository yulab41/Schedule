# P10 通讯录实体 Android RC 验收

本清单只验收微信体验版 `0.1.0-p9.20260828.55` 的原生通讯录；当前生产 `organization=true`，不提交审核或正式发布。所有号码和组织名称以当前体验版实际显示为准，不截图、不复制或外传真实号码。

## 进入与能力状态

1. 使用已绑定的管理员或普通成员账号进入当前群组，从工作台底栏打开“通讯录”。访客账号不得显示该入口。
2. 当前生产能力为 `organization=true`：成员页面可进入并按服务端权限读取目录；访客账号不得通过切换入口或请求直接获得目录。
3. 在关闭能力的隔离环境复核 `organization=false`：页面显示“通讯录暂未开放”，不出现加载中的真实号码，也不产生通讯录请求；返回工作台后再次进入，关闭态文案和导航不闪烁。

## 院内模式（能力开启的隔离环境）

1. 首次进入后科室与人员页并行读取 facets 和收藏索引，但未搜索、未筛选时不得拉取全量列表，也不得显示“没有找到”空卡。
2. 点击“人员”再返回“科室”，确认白色指示块、科室/人员图标和内容页同步运动；首次切换不出现重新加载闪屏，也不重复请求已完成的 facets。
3. 在结果列表任意位置左右横划切换两页，确认两页分别保留搜索词、筛选、结果、分页和纵向滚动位置；快速反向横划或连续点击后最终页、指示块与文案一致。
4. 依次选择院区、片区、楼宇、楼层、科室、单元、类型；每次选择都保留其他已选条件，结果摘要与列表同步更新。
5. 从导览按钮打开筛选，确认抽屉定位到对应层级；逐项折叠/展开、选择和清除，选项为全宽纵向列表且联动清理无效下级。
6. 输入科室/姓名/号码关键词并确认搜索；清空关键词且无筛选时回到闲置态，不拉取全量目录。
7. 对照 Web 结果区确认每条卡片之间都有 1px 分割线；标题、路径、标签、号码、结果摘要和筛选文字的字号、字重与行距一致。
8. 滚动到“加载更多”，确认 cursor 请求追加记录、不重复首屏、不丢失筛选条件。
9. 点击完整手机/座机号码，确认蓝色电话图标执行一次动效且只触发一次拨号；只有内线号的联系人显示为只读文本，不触发拨号。

## 员工模式与权限

1. 切换“员工”标签，确认请求 employee-directory 路径，筛选标签变为“组织根、一级组织、二级组织、三级组织、四级组织、五级组织、类型”。
2. 普通成员与管理员分别复核可见条目差异；不得通过切换模式看到超出服务端权限的条目或号码。
3. 进入/退出页面、切换科室/人员和重复点击搜索后，不出现另一模式或旧群组的结果、号码和重复请求提示。

## 通过条件

自动验收以 `organization=true` capability、目录定向/全量测试、体验版构建和生产 verifier 为准；关闭能力矩阵在隔离环境验证。默认字号稳定区域需达到相似度 ≥98%、显著差异像素 ≤2%、关键几何偏差 ≤2px，系统状态栏、胶囊和字体栅格使用批准遮罩。若任一项失败，请提供模式、尺寸、状态和现象；“P10 通讯录 RC 通过”作为实体 Android 通过记录，不触发审核或正式发布。
