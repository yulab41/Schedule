# P9 数据与消息实体 Android RC 验收

本清单只验收微信体验版 `0.1.0-p9.20260827.29` 的原生数据与消息页面。当前生产 `insights=false`、`externalMessages=false`，关闭态不得读取数据、发起订阅授权或创建导出任务；不提交审核或正式发布。访问记录、通知正文、导出文件和凭证不得截图、复制或外传。

## 入口与权限关闭

1. 使用管理员、普通成员和访客分别进入工作台 More，确认访客不显示数据/消息管理入口；成员只看到服务端允许的入口。
2. 在当前生产能力关闭策略下，访客访问、事件/统计、通知、导出和通知设置均显示明确关闭或只读提示，不产生对应 API、下载或订阅授权请求。
3. 返回工作台、前后台切换和重复进入页面后，关闭态不闪烁、不残留旧正文、号码、IP、request id 或 token。

## 只读数据与隐私

1. 在授权的隔离环境中复核访客访问聚合/日志、事件时间线和排班统计；验证月份筛选、加载更多、空态、错误重试和权限失败关闭。
2. 事件只显示类型、时间、对象和影响数量；统计只显示计划/实际、计值班次和岗位完成度，不展示原始 payload、操作 ID 或完整身份标识。
3. 访客来源按权限脱敏，原始明细保留说明和匿名聚合说明；页面不写业务缓存、日志或 visitor key。

## 通知、订阅与导出

1. 在授权的隔离环境中复核通知未读数、单条已读、全部已读和游标加载；失败时不会重复提交或丢失页面位置。
2. 保持 `externalMessages=false` 时，通知设置不调用订阅授权桥、不保存模板 ID/正文；只有明确授权并配置合规模板后才进入后续能力评估。
3. 在授权的隔离环境中创建排班/统计导出任务，验证轮询、失败重试、完成后 `wx.downloadFile` 使用登录态 header、URL 不含 token，文件只交给 `wx.openDocument`，不写相册或长期缓存。

## 通过条件

用户回复“P9 数据与消息 RC 通过”后，才允许分别评估 `insights` 和 `externalMessages` 的能力开启；若任一项失败，请提供页面、认证角色、尺寸、状态和现象。没有实体 Android 通过证据时，不提交审核或正式发布。
