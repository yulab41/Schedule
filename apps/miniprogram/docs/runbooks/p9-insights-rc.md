# P9 数据与消息授权后收口

本清单用于收口微信体验版 `0.1.0-p9.20260827.38` 及后续候选的原生数据与消息页面。用户已明确授权开启 P9 能力；当前生产 `insights=true`、`externalMessages=true`，访问记录、事件/统计、通知和导出按权限读取，订阅只在用户明确点击时请求。访问记录、通知正文、导出文件和凭证不得截图、复制或外传。

## 入口与权限

1. 使用管理员、普通成员和访客分别进入工作台 More，确认访客不显示数据/消息管理入口；成员只看到服务端允许的入口。
2. 在当前生产能力开启策略下，允许角色读取对应数据；访客、无权限角色和能力失败仍显示明确关闭/错误态，不泄露正文、号码、IP、request id 或 token。
3. 返回工作台、前后台切换和重复进入页面后，不重复请求、不残留旧正文或凭证；能力失效时页面清理并进入 disabled。

## 只读数据与隐私

1. 在授权的隔离环境中复核访客访问聚合/日志、事件时间线和排班统计；验证月份筛选、加载更多、空态、错误重试和权限失败关闭。
2. 事件只显示类型、时间、对象和影响数量；统计只显示计划/实际、计值班次和岗位完成度，不展示原始 payload、操作 ID 或完整身份标识。
3. 访客来源按权限脱敏，原始明细保留说明和匿名聚合说明；页面不写业务缓存、日志或 visitor key。

## 通知、订阅与导出

1. 在授权的隔离环境中复核通知未读数、单条已读、全部已读和游标加载；失败时不会重复提交或丢失页面位置。
2. 生产已配置合规值班提醒模板；通知设置不自动调用订阅授权桥，只有用户明确点击开启时才请求该模板，拒绝/封禁/过滤不会写入“已开启”。
3. 在授权的隔离环境中创建排班/统计导出任务，验证轮询、失败重试、完成后 `wx.downloadFile` 使用登录态 header、URL 不含 token，文件只交给 `wx.openDocument`，不写相册或长期缓存。

## 状态与尺寸矩阵

| 页面/状态                          | 390 | 320 | 大字号 | 预期                                   |
| ---------------------------------- | --- | --- | ------ | -------------------------------------- |
| 访客访问 ready/empty/error         | ✓   | ✓   | ✓      | 脱敏、可滚动、错误可重试               |
| 事件/统计 ready/empty/error        | ✓   | ✓   | ✓      | 原生 payload 不泄露，tab 可触达        |
| 通知 ready/empty/error             | ✓   | ✓   | ✓      | 已读操作幂等，不写缓存                 |
| 导出 loading/error/closed          | ✓   | ✓   | ✓      | 无 URL token，无自动相册写入           |
| insights/externalMessages disabled | ✓   | ✓   | ✓      | 关闭态无请求、无授权弹窗、无旧数据残留 |

## 自动通过条件

自动矩阵、生产能力探针、隐私/安全下载检查、体验上传和 `ecs-verify.sh` 全部通过后，视为本轮 P9 自动 RC 通过。正式审核/发布使用用户已明确授权的候选；若微信平台返回失败，保留当前生产 release 和能力配置并记录平台错误，不改写业务数据。
