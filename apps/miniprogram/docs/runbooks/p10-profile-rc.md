# 个人中心实体 Android 验收

当前范围：UX-CLEANUP-10 Q1/Q5。总控发布记录决定实际体验版版本、源码与 manifest，旧版号不作为默认值。
测试只读取本人资料与排班；密码、退出和解绑使用隔离测试账号。不得外传真实身份和业务资料。

## 页面与导航

1. 进入“我的”，正文不再重复显示个人中心大标题及右侧圆头像；固定导航和必要返回保留。
2. 顺序为身份卡、值班概览、下一班、值班节奏、账户设置、退出登录。下一班与值班概览同用白底淡蓝光晕，文字清晰。
3. 查看完整统计靠卡片右内边缘，点击进入当前群组统计；打开排班日历返回原工作台。
4. 访客隐藏统计与下一班，无群组保留身份与账户设置，无下一班保留空状态。

## 文字标识与微信身份

1. 微信快捷登录始终是普通登录动作，登录前后均不弹出照片选择，不读取或上传照片。
2. 人物标识为姓名首字，账户设置无微信头像行，不提供照片编辑或删除操作。
3. 微信小程序身份只显示真实绑定结果。失败点击重试；请求期间不重复请求，未成功不能显示已绑定。
4. 仅服务端允许时显示解除绑定，不展示 OpenID、UnionID 或微信号。
5. 历史照片表、记录与文件保留；仅旧照片缓存元数据按已确认键前缀清理，不清空登录态或偏好。

## 密码与会话

1. 点击“修改登录密码”：账号密码登录填写当前密码、新密码和确认；微信登录沿用新的微信证明。
2. 修改成功后重新登录；错误或取消保留可恢复状态。退出登录不删除业务资料或微信绑定。
3. 退出或换账号后，旧绑定请求不能覆盖新账号；尚未登录显示登录入口。

## 尺寸与证据

390×844、320px、大字号分别检查右对齐、无横向溢出、白底文字对比、空状态及触控区域。
浏览器代理与 Node 自动化只能证明对应层级，小米14同构建体验版真实操作才是原生验收。
本轮不提审、不正式发布；没有真机证据时状态为待用户复核。

进入已登录与尚未登录页面各两次，两次都不得白屏；退出、解绑和密码变更仅使用隔离测试账号。
验收前从总控发布记录核对本轮版本、源码与 manifest；能力开关读取该部署的真实配置，不沿用历史组织能力状态。
