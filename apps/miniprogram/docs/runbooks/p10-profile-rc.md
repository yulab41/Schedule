# P10 个人中心实体 Android RC 验收

本清单只验收微信体验版 `0.1.0-p9.20260827.30` 的原生个人中心；当前生产 `organization=true`，个人中心不依赖该能力，`insights`/`externalMessages=false`，不提交审核或正式发布。资料只在当前会话内展示，不截图、不复制或外传真实姓名、账号和版本信息。

## 入口与登录态

1. 使用体验版 `.30` 登录后，从工作台顶部头像进入“我的”；确认返回按钮回到排班台，标题和 `buildLabel` 可见且不闪烁。
2. 使用已绑定普通成员 D0796 的微信快捷登录，确认资料卡显示真实姓名、`微信快捷登录`、资料版本和首字头像；进入页面期间不产生新的个人资料网络请求。
3. 使用后台管理员账号密码登录，确认资料卡显示 `账号密码登录`；“微信绑定”仅显示“账号密码登录无需解除微信绑定 / 不适用”，不得出现“解除当前微信绑定”按钮。

## 会话与解绑边界

1. 微信认证会话进入“解除当前微信绑定”，确认仍进入既有解绑确认页；取消后返回个人中心，不清理排班资料。
2. 在微信认证和账号密码两种会话分别点击“切换登录方式”和“退出当前会话”，确认清理当前本地会话后回到双入口，不删除业务资料或账号。
3. 清理会话后直接打开个人中心，确认显示“尚未登录”和“进入登录”，不显示旧姓名、认证方式或解绑操作。
