# P10 个人中心 Web 对等实体 Android RC 验收

本清单验收 production-profile 体验版 `0.1.0-p9.20260828.64`。生产 `organization=true`、
`insights=true`、`externalMessages=true`；测试只读取本人资料与排班，密码和
解绑操作使用专用测试账号。不得截图、复制或外传真实姓名、联系方式、头像和排班内容。体验版不提交审核或正式发布。

## Web 1:1 内容与导航

1. 冷启动进入工作台后立即从顶部或底栏进入“我的”，再返回日历重复进入；两次都不得白屏，最慢只能显示“正在准备个人中心”或页面自身 loading。
2. 确认顺序为：页面标题、身份卡、值班概览、值班节奏、下一班、
   账户设置、退出登录；深蓝“下一班”是唯一深色焦点。
3. “查看完整统计”进入当前群组统计页；“打开排班日历”回到工作台日历，不重建当前会话。
4. 访客隐藏值班概览、节奏和下一班；无群组账号仍显示身份与账户设置，群组显示未加入状态。

## 头像与微信小程序身份

1. 使用微信快捷登录，点击按钮后登录立即继续；选择头像则在进入工作台后同步，取消选择仍正常登录。
2. 退出登录再进入时本地头像副本已清除；重新登录按 `avatarVersion` 认证下载，服务端头像仍保留。
3. 账户设置显示“微信小程序身份”和“微信头像”，不显示微信号、OpenID 或 UnionID。
4. 点击“恢复姓名首字”先出现确认；取消不变，确认后双处头像回退姓名首字且下次登录仍保持。
5. 仅在状态为可解绑时显示“解除绑定”；账号密码登录若该账号已有当前 AppID 绑定，也按服务端资格显示。

## 密码、会话与错误

1. 点击“修改登录密码”：账号密码登录填写当前密码、新密码和确认密码；微信快捷登录使用新的微信 code
   证明，不显示当前密码输入框。
2. 修改成功后旧会话清除并回到登录；错误密码、取消微信证明或网络失败保留当前会话并显示可恢复错误。
3. 点击“退出登录”只清本机会话与本地头像副本，不删除业务资料、微信绑定或服务端头像。
4. 清理会话后打开个人中心显示“尚未登录”和“进入登录”，不残留旧账号数据。
