# ADR-0004：账号不注销，只解除当前小程序身份

- 状态：已接受
- 日期：2026-08-17

## 决策

产品不提供账号注销。用户或平台管理员只能解除当前正式小程序 AppID 的 identity；其他微信渠道、业务用户、用户名、群组、排班和审计不变。

解绑前必须存在可用 Web 用户名和密码。用户提交新的微信 code，管理员提交原因；操作幂等，提高 `authVersion` 并使旧小程序 session 立即失效，允许立即重新绑定。

## 后果

代码、契约、页面和隐私文案不得把解绑表述为注销或删除用户。未来如需账号注销属于新的产品、合规和数据保留决策，必须新建 ADR 并由用户确认。
