# 设备与兼容矩阵

## 必测组合

| 通道             | 设备/视口             | 用途           | 门槛                               |
| ---------------- | --------------------- | -------------- | ---------------------------------- |
| Storybook        | Chromium 390×844      | 黄金设计       | 视觉、交互状态、A11y               |
| Storybook        | Chromium 320×844      | 窄屏边界       | 无溢出/截断，触控区达标            |
| MiniTest Android | P1 首次运行后锁定型号 | 性能主基线     | 视觉三指标、TTI、矩阵、手势        |
| MiniTest iOS     | P1 首次运行后锁定型号 | 平台差异       | 视觉三指标、字体、弹层、滚动       |
| 用户 Android     | 用户现有实体机        | 手感和系统行为 | 字体、键盘、网络、前后台、用户确认 |

## 字号和环境

- 默认系统字号是逐像素基线。
- 至少一个大字号档验证可重排和可滚动。
- Android/iOS 均覆盖普通网络、弱网/断网、前后台切换、冷启动和 24h 只读缓存。
- 低于基础库 3.0.2 的客户端明确不支持，不为其维护 WebView fallback。

具体云设备型号只能从实际 MiniTest 可用清单中选择并记录，不在 P0 猜测。
