# 设备与兼容矩阵

## 必测组合

| 通道           | 设备/视口              | 用途          | 门槛                            |
| -------------- | ---------------------- | ------------- | ------------------------------- |
| Storybook      | Chromium 390×844       | 黄金设计      | 视觉、交互状态、A11y            |
| Storybook      | Chromium 320×844       | 窄屏边界      | 无溢出/截断，触控区达标         |
| 开发者工具 GUI | 用户人工操作           | 编译/路由预检 | 四页可打开、无编译错误          |
| 用户 Android   | 用户现有实体机         | P1 必测主基线 | 视觉、TTI、矩阵、手势、用户确认 |
| 人工 iOS       | 后续 RC 可安排的实体机 | 平台差异      | 字体、弹层、滚动、系统行为      |

## 字号和环境

- 默认系统字号是逐像素基线。
- 至少一个大字号档验证可重排和可滚动。
- P1 PoC 先在用户 Android 覆盖当前四页；含业务网络/缓存的后续 RC 再人工覆盖普通网络、弱网/断网、前后台切换、冷启动和 24h 只读缓存。
- 低于基础库 3.0.2 的客户端明确不支持，不为其维护 WebView fallback。

P1 用户反馈通过即可进入 P2；若用户提供设备型号、Android/微信版本和显示/字号设置则写入状态，未提供不阻断本轮。iOS 人工复核在正式发布前另行安排，不使用云测替代。
