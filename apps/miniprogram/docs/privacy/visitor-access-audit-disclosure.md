# 访客访问审计隐私披露清单

本清单对应访客查看已发布排班时新增的访问审计。上线前必须在微信公众平台的“小程序用户隐私保护指引”中同步披露；代码完成不代表平台侧披露已经完成。

## 收集范围与用途

- 服务端记录访问时间、查看月份、完整请求 ID 和来源 IP，用于群组入口安全审计与故障定位。
- 客户端在可获得时上报品牌、型号、操作系统、平台、CPU/ABI、内存与性能等级、微信版本、基础库版本、语言、主题、调试状态、小程序版本与环境、屏幕/窗口尺寸、像素比、字体设置、安全区和网络类型。
- 客户端环境属于“客户端上报，可能被伪造”，只用于审计展示，不得用于认证、授权、风控放行或成员身份判断。
- `wx.login` 临时代码仅用于服务端向微信换取当前小程序范围的 OpenID；临时代码与 `session_key` 不落库、不写日志、不返回客户端。OpenID 不是微信号。
- 换码失败不阻断访客查看排班，记录标记为未取得 OpenID。

## 不收集范围

本功能不请求昵称、头像或手机号授权，不取得微信号、IMEI、MAC、设备序列号或已安装应用。访客读取不会创建业务用户、群组成员关系或登录态。

## 可见性与保留

- 只有具备 `viewVisitorAccessLogs` 权限的用户可以查看访问明细。
- 原始访问明细最多保留 90 天，随后按既有任务删除；匿名月份聚合继续保留且不包含 OpenID、IP、请求 ID 或设备上下文。
- 访客密钥、`wx.login` 临时代码、`session_key` 和完整请求/响应正文不得进入访问日志。

## 上线门禁

1. 在微信公众平台隐私保护指引中声明上述数据类别、用途、保留期限与访问权限。
2. 验证平台要求的首次隐私确认流程；不得承诺绝对“零提示”。
3. 用正式候选构建验证 `wx.login` 失败降级、90 天清理与权限隔离。
4. 仅在平台披露生效后启用生产访客详细审计。
