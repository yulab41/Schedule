# Web 安全检查

- [ ] 所有业务接口要求认证并校验群组、角色和资源归属。
- [ ] 跨群组读取和写入均返回安全的 403/404，不泄露名称、成员或联系方式。
- [ ] 群组码、登录和敏感接口有限流；写入校验输入、版本和幂等键。
- [ ] 事务覆盖排班发布、请假、换班、加扣班、审批和成员状态变化。
- [ ] 日志不含密码、令牌、完整手机号或原始敏感请求体。
- [ ] 导出不含手机号；离线只读；缓存按用户和群组隔离。
- [ ] 备份加密、恢复演练、审计日志和删除/恢复策略可验证。

验证入口：`tests/security`、`pnpm verify`、`pnpm smoke:browser`。
