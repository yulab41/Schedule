# Web 测试、安全与验收

## 自动化验证

```powershell
pnpm verify
pnpm smoke:browser
pnpm smoke:check-core
```

覆盖单元、集成、并发、安全、性能、Web build 和浏览器流程；性能测试使用隔离 MySQL，不含公网网络延迟。

## 安全门禁

- 所有接口校验认证、群组、角色、资源归属、输入、版本和幂等语义。
- 跨群组失败不得泄露名称、成员或联系方式；日志不含密码、令牌、完整手机号或原始敏感请求体。
- 排班发布、请假、换班、加扣班、审批和成员状态变化使用事务与版本保护。
- 导出不含手机号；离线只读；缓存按用户和群组隔离。
- 备份加密、恢复演练和审计日志可验证。

## Web 1.0 验收

- 登录后直接看到当前月份值班人员。
- 管理员可建立、预览、发布和维护排班；并发修改有保护。
- 日历支持月/周/列表、节假日、变更标记、筛选、详情和联系方式操作。
- 工作流、事件、统计和导出结果可追溯且不泄露敏感数据。
- 正式发布顺序：备份 → 开发环境验收 → 明确批准 → ECS 部署/迁移 → 生产 smoke → 版本标签。

## 发布标准

所有自动化检查、浏览器 smoke、安全检查、备份恢复和回滚准备完成后，才允许进入正式发布窗口。
