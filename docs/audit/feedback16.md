# Feedback16：访客加载、返回登录与二维码长按

## 结论

- CSV 已生成，真机错误发生在 `wx.downloadFile` 的微信合法域名校验阶段。生产构建下载地址固定为 `https://hosp.schedule.eylinhome.top/api/groups/.../exports/.../download`；这是公众平台 `downloadFile` 合法域名配置问题，不是账号导出权限、CSV 内容或 API 代码错误。代码继续使用 Bearer 请求头，不使用 URL token 绕过。
- 匿名访客页从 `890efd8b` 起在每次月/周/列表切换时清空页面、重新 resolve 访客码并读取当前及相邻月份；成员页会复用内存月窗。该差异是频繁显示“正在读取排班”的代码根因，不仅是正式版 103 较旧。
- 二维码相册保存链路来自 `9bae5beb`，现按用户要求删除；PNG/JPEG 原字节识别和访客码轮换保留，改由微信图片长按菜单保存或转发。

## 修改

- 匿名访客页仅在 Page 生命周期内保存已解析群组、月份、节假日和进行中请求；三视图复用已加载月窗，缺少当前月才显示全页加载，相邻月份后台补齐。重复请求合并，迟到响应受页面 serial 与 context generation 双重隔离。
- hide/unload、显式重试、访客码 403/404/410/失效都会清空访客内存、电话、事件及筛选状态；没有写入 Storage，也没有改变成员工作台缓存。
- 原顶部纯文字“返回”移到匿名访客页视图控制行，成为“返回登录”描边按钮，位于视图切换与筛选之间。复用 `ui-chevron-left.svg`，按压位移和 reduced-motion 均为访客页局部样式；成员页面和共享组件未改。
