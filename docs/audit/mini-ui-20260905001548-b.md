## 交接与停止条件

### 退出按钮宽度依据与补充 red/green

- 用户本轮总控 review 明确指出：414px 原图的退出按钮约 184px，必须保留。Mini 基线未声明宽度，外观取决于原生默认样式；
  Web `.profile-sign-out` 为 inline-flex/content width，当前 token 中没有对应 184px 宽度 token。
- 没有取得当前微信原生默认 CSS 的运行时输出；不把浏览器 `auto` 宽度或人为默认样式当作原生事实。
  184px 的选择来源是用户原图及本轮明确保留要求，因此将此约束直接写在 Mini 专属 `.profile-sign-out`，并限制 `max-width: 100%`。
- 新增精确宽度断言后，414px 定向用例先实测 `90 != 184` 失败（`width-red.json`），再改为显式 184px。
  随后全视口 12 项测试通过，30 个 Profile 状态的退出宽度均为 184px。表单、事件和退出业务语义未改变；
  危险色、边框、圆角和水平 padding 仍使用原设计。
