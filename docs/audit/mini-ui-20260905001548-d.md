## 实现与行为变化

1. 新增受控 `ui-toast`：`visible/title/message/tone`，tone 为 `success/info/warning/error`，未知 tone 回退 info。可选 `topOffset` 为额外安全下界，计算后保留 8px 间距。
2. `virtualHost + root-portal`，实际层为 fixed，层级 `dialog token + 100`，高于现有 Sheet 的 400。层、卡片和文本均 `pointer-events:none`，无遮罩或触摸 handler。
3. 短标题单行，正文最多两行，完整文本仍在可访问名称中；语义 border/text/background、系统字体、胶囊圆角和阴影全部复用 tokens。未新增或复制 SVG，不引入私有图标。
4. `platform/top-overlay.ts` 读取 `getWindowInfo`、有效 menu button rect、status bar/safeArea，以及当前 Page 既有自定义导航的 `shellHeaderHeight`。三份 workflow controller 仅把已有 `headerHeight` 同时暴露为数字；原布局表达式不变。嵌入工作台直接复用其已有 shellHeaderHeight，无需修改 workbench。
5. 可见时重新计算偏移；窗口 resize 和页面 show 重新读取；detach 移除同一 resize listener，并用 attachment identity 拒绝旧回调。没有硬编码设备顶部坐标。
6. 组件常驻且不占流；父级清空消息后保留最后一次文字供 CSS 的 120ms 淡出/上移使用，隐藏态设置 aria-hidden。减少动态模式关闭 transition/transform。业务时长仍为原 host 的 2000ms，组件没有 timer。
7. host 原 timer 增加消息 token，已进入队列的旧回调不能清掉同值新提示；拒绝失效 controller 的 observer 创建新 timer。Page hide/pageLifetimes.hide 清理 timer，返回时丢弃隐藏期间旧反馈。
8. 既有 controller 身份、异步 task 检查、this/receiver 绑定、Promise/catch 边界、错误内容、API 调用、请求次数与持久业务状态均保留。隐藏页面的业务请求仍按原语义完成；本修改只停止隐藏页的反馈 timer，不宣称取消网络请求。
