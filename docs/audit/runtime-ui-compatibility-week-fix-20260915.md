# Skyline 3.17.2 周视图与圆角兼容修复（2026-09-15）

## 结论与范围

同一小米 14、同一体验版 `.134@5c02393`、同为后台管理员的两微信实例进一步证明：
基础库 3.17.2 的异常不属于账号、权限或排班数据差异。3.17.2 下周视图选中框、页头固有尺寸、
组合圆角边框和周 Swiper 状态转换均与 3.17.3 不同；同一异常实例的月视图正常。

本轮只在 `SDKVersion === 3.17.2` 时启用以下后备：

- 周视图复用月视图已经使用的 `calendar-period-pager` 三槽环形状态机，保留 240ms 动画、
  `easeOutCubic`、提交锁和有界队列；不再执行旧周视图的动画后强制归中。
- 周选中框直接绘制 inset `box-shadow`，避开 3.17.2 未稳定绘制的 `::after`。
- 页头群名使用明确的可用宽度，避免 `fit-content`/文本固有尺寸差异；菜单保持现有固定页头层级。
- `ui-toast` 把粗左边框改为父圆角裁剪下的实体色条，避免粗边框与圆角组合退化为竖条。

3.17.3、后续版本和无法读取版本的运行时继续走原周视图归中、原伪元素、原页头和原 Toast
边框路径。未修改 API、权限、账号、排班数据、列表/月视图或依赖。

## 引入点与原因

- `733e3af6`：周/列表使用 `periodSwiperDuration: 0` 与 `current: 1` 同批归中；同时引入页头
  `width: fit-content` 和群名 `max-width`。3.17.2 会对周归中产生反向动画或重复完成事件，
  且固有尺寸计算更窄。
- `50c6d1ed`：周选中框改由 `.week-day.is-selected::after` 绘制；3.17.2 真机不显示该伪元素框。
- `cdb759b9`：Toast 使用 `border-left: 4px` 叠加父圆角；3.17.2 真机把左侧圆弧显示为直竖条。

以上引入点由对应文件的 `git log -S` 和 `git blame` 核对。Swiper 原生错序属于同版本真机
行为证据；Node 自动化只能验证状态机、调用次数与正常路径隔离，不能替代实体机动画验收。
