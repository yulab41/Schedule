## 九项行为变化

1. 群组默认与个人偏好删除内层卡片装饰，分区之间保留横线；单独个人分区无横线。
2. 手排未选中班种白底、班种色文字/边框；选中使用配置的背景和文字颜色。
3. 矩阵滚动边界读取容器实际宽度，不再估算屏幕外边距；更新布局、返回编辑和窗口变化后重新测量，过期测量不提交。
4. 矩阵高度为 82px 表头加每人 44px。纵向滚动范围为零时，WXS 不截获纵向手势、不启动纵向惯性；横向仍由原四层坐标源驱动。
5. 月历班种标识固定正方形且不压缩：常规 13px，窄屏 11px，保留单字和颜色。窄屏紧凑月历调整单元格内距，避免三字姓名被标识挤压。
6. 手排预览外壳只保留间距，月历自身独立负责边框和圆角。
7. calendar-month 与 schedule-calendar-preview 增加 shadow 选项，默认保持原外观；预览弹窗关闭月历阴影。原弹窗随月份高度变化的逻辑保留。
8. 默认日期增加 loading/ready/error 状态。加载时占位、隐藏矩阵、禁止保存/预览；失败可重试或手动选择。岗位、模板、手选日期和卸载都会使过期响应失效。
9. CSV 保留鉴权下载，删除 openDocument，下载后提供用户主动点击的“发送文件”。文件名独占一行、按钮独立换行且四周 8px 内距，复用 UiToast；生成/下载/发送状态不再互相矛盾。取消发送为中性提示，不自动重试或生成新任务。

CSV 临时文件路径只在实例私有状态保存；重置、切群、卸载、重复下载、失败 HTTP 和过期异步响应都清理对应临时文件。请求代次隔离旧创建/轮询/下载/发送响应。原生失败只保留 domain/timeout/tls/network/http/empty/unknown 分类与数字 HTTP 状态，不记录原始 errMsg、URL、凭证或文件路径。代码中生产下载目标为 https://hosp.schedule.eylinhome.top；微信后台 downloadFile 合法域名是否包含它不能由本地构建确认，需新体验版失败分类或平台实际配置证据。

月历新增 holidays 输入，复用现有节假日接口与名称缩写，不增加服务端接口。预览、草稿及发布记录按显示月和相邻月份覆盖年份，缓存成功年份、失败后可重试。迟到节假日不会重置当前月份或在卸载后写入页面。非拟排日期继续使用用户此前确认的灰色禁用样式，节假日标签仍可见。
