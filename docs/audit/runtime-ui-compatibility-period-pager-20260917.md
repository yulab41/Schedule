# Skyline 3.17.2：月历/日期分页改原生滚动（体验版 155）

日期：2026-09-17　作者：Codex　授权：用户当次报障 + 既有「可自行提交、放行、上传」授权

## 用户报告（均只在 3.17.2；3.17.3 正常）

1. 请假页年月日选择器：定位按钮落下的是**临近月**而不是当月，且**没有跳转动画**；要求是"跨多个月也只做一个月的跳转动画"。
2. 请假页选择器左右切换仍会**反跳**。
3. 首页月历定位按钮同样问题（临近月 + 无动画）。
4. 首页月历左右切换**无动画**、内容**不跟手**（手势滑动正常）。

同时用户确认：3.17.2 的滚轮"已经和 3.17.3 基本一样"，并且低速时末尾更顺滑——**这一条是优点，本轮不动**。

## 根因

两处的程序化切页都是"3 槽环形 `swiper` + 改 `current`"。3.17.2 无法动画化程序化跳转（并会反向重播圆形滑动），所以此前一轮把它设成 `duration: 0` 并手动补一次结算。后果正是本轮四条：**没有动画**（1、3、4）；而手动结算依赖"当前槽 == 目标槽"，一旦错过就丢结算 → 环形状态与画面错位 → **落到临近月 / 反跳**（1、2、3）。

## 实现（3.17.3 分支逐字未改）

按当轮确立的原则（最小改动优先；当低版本无法在原实现上适配时，为它设计匹配的实现而不是硬打补丁），把 **3.17.2 的分页换成原生横向 `scroll-view`** —— 与滚轮同一条已真机验证过的通道：

- 环形三面板、面板标记、插值/高度逻辑全部复用；面板体抽成 WXML `template`，swiper 分支与 scroll-view 分支**共用同一份面板标记**。
- `scroll-into-view` + `scroll-with-animation` 让平台自己动画**一个面板**；`bindscroll` 提供度量并驱动结算，手势滑动与程序化切换走**同一套结算代码**（所以跟手、反跳都消失）。
- 共享助手（度量合并、最近槽、面板 id、结算延时）放在 `calendar-period-pager.ts`，两个组件共用，不存在两套实现。
- 定位今天：先"无感归位"（同一月份内容，视觉无变化），再**单面板动画**滑到当月——跨多少个月都只滑一格。
- 3.17.3 仍走原 `swiper` 分支（`wx:else`），`swiperDuration`/`swiperCurrent` 行为与上一版相同。
