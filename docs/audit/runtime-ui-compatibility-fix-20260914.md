# 小程序 Skyline 3.17.2 UI 兼容修复

## 结论

异常已定位为微信单实例使用的基础库/Skyline CSS 运行时差异，不是项目组件库版本漂移。关键对照均来自同一体验版 `0.1.0-p10.20260914.133@2d7f685`：

| 项目                | 异常实例         | 正常实例         |
| ------------------- | ---------------- | ---------------- |
| 基础库              | 3.17.2           | 3.17.3           |
| Grid 双列           | 退化，顶部差 8px | 同行，顶部差 0px |
| CSS 缺口圆          | 截图为尖角       | 截图为圆弧       |
| SVG 完整圆          | 正常             | 正常             |
| CSS 变量 / 显式滚动 | 正常 / 正常      | 正常 / 正常      |

因此采用精确 3.17.2 兼容分支，不改变 3.17.3 及以上实例的原视觉代码路径。设计记录见 `docs/superpowers/specs/2026-09-14-miniprogram-skyline-3172-ui-compatibility-design.md`。

## 实现与行为变化

- 新增无依赖的运行时判定：仅 `SDKVersion === '3.17.2'` 返回 true；版本缺失、API 不可用或读取失败均保留正常路径。
- 仅在 3.17.2 下，将工作台/访客详情、通讯录卡片、平台账号、排班配置及统计面板的生产 Grid 容器切换为局部 Flex 布局。
- 仅在 3.17.2 下，将共享 `ui-loading`、工作台/访客加载态和请假/换班/加扣班工作流加载圈切换为本地 SVG；尺寸、颜色及动画节奏与原路径对齐。
- 诊断页和手势探针的 Grid 不替换，以免兼容代码掩盖诊断结果。
- 没有修改登录、成员/访客数据、日历计算、电话动作、工作流控制器语义、接口、权限、缓存或生产配置。

## 正常实例零视觉改动边界

- 3.17.3 的判定测试明确返回 false。
- 原 Grid 声明、原 CSS 圆环节点和原样式均保留；只有 3.17.2 才附加兼容 class 或进入 SVG `wx:else`。
- 因而源码层面 3.17.3 仍执行原布局与原加载圈。是否达到像素级不变仍需新体验版的小米 14 原生截图确认，不能用 Node 或构建结果替代。
