# Web 1.0 调试与验证

本文件只记录当前 Web 问题、根因、行为变化和验证结果；历史细节以 Git 提交为准。

## 规则

- 回归修复先用 `git log -S`、`git blame` 定位引入点，再补失败测试。
- 审计接收者绑定、异步错误、空值、调用次数、副作用和权限边界。
- Web 核心链路变更记录 `pnpm smoke:browser` 与 `pnpm smoke:check-core`。
- 状态使用：已实现待浏览器复核 → 已完成 → 待用户复核。

## 当前验证

- 文档 Prettier：通过。
- Web build：通过。
- 浏览器 smoke：登录、管理员、成员、访客及访问记录流程 7/7 通过。
- `pnpm smoke:check-core`：通过。
- 本轮仅压缩文档，未修改 Web 或服务端源码。

## 后续

新问题只记录一条短条目：反馈、根因/引入点、修复、验证、状态。不要复制完整终端输出或逐轮历史。
