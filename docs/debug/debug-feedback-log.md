# Web 1.0 调试反馈日志

本文件只保留 Web 1.0 的调试记录和运行验证结果。产品语义以 Web 源码、Contracts、API 和数据库规则为准。

## 记录规则

- 每轮记录用户反馈、根因、行为变化、验证命令和当前状态。
- 回归修复先用 `git log -S` 与 `git blame` 定位引入点，再补失败测试并实现修复。
- Web 核心链路改动必须记录 `pnpm smoke:browser` 与 `pnpm smoke:check-core` 的结果。
- 运行验证通过后，状态依次使用“已实现待浏览器复核”“已完成”“待用户复核”。

## Web 验收基线

- 登录后可查看当前月份日历和值班人员。
- 管理员可通过自动或手动方式建立、预览、发布和维护排班。
- 请假、换班、加扣班、审批、事件追踪和通知遵守服务端权限、版本和事务约束。
- 群组、成员、岗位、班种、联系方式和访客数据按群组边界隔离。
- 月度、年度、周末、节假日和加扣班统计可复核，导出不包含手机号。
- 离线状态只允许查看缓存，不允许提交业务变更。
