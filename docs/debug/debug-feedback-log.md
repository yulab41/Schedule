本文件是 Web 1.0 调试与测试阶段的用户反馈、修改意见、自查发现、修复与功能变更的持续记录。
每一轮修复对应一次 Git 提交；`docs/project-status.md` 保留当前状态交接，本文件保留完整轮次历史。

当前阶段：Web 1.0 线上调试与用户测试（功能已基本完整，按用户反馈持续修复/打磨），完善后进入微信小程序立项与实施（设计规格 26.1，另建独立实施计划）。

## 通用注意事项（调试期）

- PWA 缓存：Web 改动上线后提醒用户强制刷新；必要时升级 `apps/web/src/pwa/cache-logic.ts` 的 shell/schedule 缓存版本号。
- 部署：GitHub Actions 的 Deploy 由 Verify 成功触发；Verify 失败会导致该提交不部署（曾出现一次，见轮次 9）。判断是否上线以 `gh run list` 为准。
- 数据库：CynosDB 默认 `explicit_defaults_for_timestamp=OFF`，TIMESTAMP 列会隐式带 `ON UPDATE CURRENT_TIMESTAMP`，曾导致批量更新班次触发唯一键冲突（已修复并新增迁移 `0018`，见轮次 10）。后续涉及 TIMESTAMP 列定义时需显式写明默认值。
- 数据清理：2026-08-03 已按用户要求清空线上草稿与排班（23 个排班期间、638 条班次软删除，统计快照清空；模板/成员/岗位/班种/联系方式/事件历史保留）。
- 提交与推送：每轮完成验证后自动 commit 并 push `main`，CloudBase 部署由流水线自动执行。
