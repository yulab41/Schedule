# 网页校对基线重设实施批次

依据：[用户批准的重设口径与设计](../specs/2026-10-21-external-duty-rebaseline-design.md)。只修改 API、数据库和必要发布校验；现有小程序无需重传。

1. 保存一次性实际排班快照：迁移 0072、schema、备份表数和发布门禁；不改原排班或历史操作。
2. 扫描、预览校验、同步、撤回读取统一基线；撤回再发布使旧快照失效，普通合并保留未替换日期。测试必须先红后绿。
3. 定向单元/迁移/真实发布生命周期测试、API/数据库 build/typecheck、ESLint、格式、Shell 和 core smoke；只读评审后更新状态并决定检查点。

停止条件：真实 MySQL 迁移及生命周期验证被阻塞时保留工作树、不宣称完成、不提交或部署。验证通过后提交/正常推送。生产连接和备份部署须按当次明确授权进入 L4；不上传体验版、不修改版本放行。
