# 小程序 Skyline 3.17.2 UI 兼容设计

## 状态

用户已确认按本设计实施。范围只包含微信基础库 3.17.2 的显示兼容，不改变业务数据、交互流程、API 或权限。

## 已确认事实

- 同一体验版 `0.1.0-p10.20260914.133@2d7f685`、同一 Xiaomi 14、Android 16、微信 8.0.77、412×915 和字体 18 下，基础库 3.17.2 的受控 Grid 探针退化为纵向块流，顶部差 8px；基础库 3.17.3 的顶部差为 0px。
- 3.17.2 截图同时显示 CSS 边框圆环成尖角，SVG 完整圆正常；3.17.3 的 CSS 圆环正常。
- 两个实例的 CSS 变量继承和显式纵向 `scroll-view` 测量均正常。
- 项目没有会在手机端动态下载的第三方 UI 组件库，因此差异位于微信基础库对应的 Skyline/CSS 运行时。

## 方案

- 运行时只在 `SDKVersion === '3.17.2'` 时开启兼容标记。3.17.3、后续版本、无法读取版本或读取异常时全部保留原路径。
- 3.17.2 的生产 Grid 容器使用局部 Flex 等价布局；诊断页 Grid 探针保留，用于继续识别运行时能力。
- 3.17.2 的 CSS 边框加载圈使用同尺寸、同颜色、同转速的本地 SVG；其他版本继续渲染原 CSS 圆环节点和原样式。
- 不新增依赖，不尝试在代码内触发微信基础库更新，也不提高 `libVersion` 形成全量阻断。

## 外观不变约束

- 正常路径的既有 WXML 节点和 Grid/CSS 规则不修改；兼容规则必须带 `is-skyline-3172-ui` 或条件分支。
- 3.17.3 必须对兼容判定返回 false；未知版本同样 fail-open 到原视觉。
- 自动化只能证明分支、源码和构建边界，最终视觉仍以同一新体验版在两个微信实例上的小米 14 截图为准。
