# 小程序 Skyline 运行时诊断增强设计

- 日期：2026-09-14
- 故障基线：体验版 `0.1.0-p10.20260914.132@44034fcc`
- 状态：待用户书面复核

## 目标

在不修改业务页面布局、业务逻辑、接口、权限或数据的前提下，让无法滚动测试工具页的异常微信实例，也能在首屏完成一次点击并复制足以区分下列边界的脱敏报告：

1. 微信 App 版本、基础库版本、Skyline、屏幕和字体环境差异；
2. Skyline 页面全局滚动与显式纵向 `scroll-view` 的差异；
3. CSS Grid 两列布局是否退化为块级纵排；
4. 跨自定义组件继承的 CSS 变量是否生效；
5. CSS 边框加载圈与静态 SVG 参考图是否出现不同绘制结果。

诊断结果只用于确定故障层，不直接宣称某项业务 UI 已修复。

## 已选方案与备选

### 已选：首屏自包含诊断

将测试工具改为 Skyline 明确支持的固定页面壳加纵向 `scroll-view`。在滚动内容之前放置“运行时兼容性”卡片、可见参考图和“复制首屏诊断”按钮。页面 ready 后只读测量受控探针的矩形位置，并把结论合并进现有安全报告。

优点是异常手机无需滚动即可取证，且一次体验版即可同时观察环境、布局和图形绘制。代价是测试工具页自身需要小幅结构调整。

### 未选：只增加日志

不调整页面滚动，只增加报告字段。异常实例仍无法触达底部复制按钮，不能解决当前取证阻塞。

### 未选：直接修复全部业务布局

立即将生产 Grid、加载圈和页面滚动全部改写。现有证据尚不能区分异常实例的基础库、样式能力和图形绘制边界，先大范围改业务 UI 会混淆根因。

## 页面结构

```text
固定页面壳
├─ 首屏抬头：版本 + 环境
├─ 运行时兼容性卡片
│  ├─ Grid 自动测量结果
│  ├─ CSS 变量继承自动测量结果
│  ├─ CSS 加载圈 / SVG 参考图
│  └─ 复制首屏诊断
└─ 纵向 scroll-view
   └─ 现有完整测试工具内容与完整报告按钮
```

视觉继续使用现有医疗蓝灰令牌。兼容性卡采用紧凑的“设备体检单”表达：通过、异常、暂未验证三态，不增加装饰性动效。按钮触控高度不小于 44px，320px 宽度下不产生横向溢出。

## 测量与数据流

页面进入时先同步生成已有设备信息，再在首个渲染提交完成后执行一次本地 `SelectorQuery`：

- Grid 探针包含两个固定尺寸子项。同行且第二项位于第一项右侧为通过；纵向排列或测量缺失为异常/暂未验证。
- CSS 变量探针由独立叶组件读取页面令牌并以可测宽度呈现。宽度命中预期值为通过；命中显式回退值为异常。
- 显式 `scroll-view` 的 viewport 与内容高度只记录正值/零值/缺失分类，不读取或保存业务内容。
- 加载圈与 SVG 参考图由用户截图判读；报告明确标注自动测量不能判断圆弧像素形状。

刷新只重新读取这些只读环境和布局数据。复制动作使用现有剪贴板能力，不发送网络请求。

## 隐私与故障处理

报告继续禁止账号、姓名、手机号、群组、日期、排班、请求正文、响应正文、Header、凭证和原始堆栈。探针只输出固定名称、`pass/fail/unavailable`、宽高和相对位置分类。

任何 API 或布局查询不可用时显示“暂未验证”，不能阻止页面呈现、滚动或复制。页面隐藏或卸载后的回调必须丢弃，避免迟到 `setData`。

## 验证

实现顺序为回归先红后绿：

1. 旧版测试证明首屏缺少复制入口、测试工具依赖页面全局滚动、没有 Grid/CSS 变量探针；
2. 新版结构测试证明使用 `disableScroll:true` 和显式纵向 `scroll-view`，首屏按钮位于滚动容器之前；
3. 控制器测试覆盖 Grid 通过、纵排失败、CSS 变量回退、查询不可用、刷新、隐藏和卸载迟到结果；
4. 现有完整报告字段和隐私上限保持不变；
5. 运行 Mini TypeScript、定向测试、完整 Mini 测试、production verify、Worklet/包体/确定性和上传前检查。

自动化结果只属于静态、Node 和构建证据。真正的异常微信实例报告与截图仍是定位具体运行时差异的必要证据。
