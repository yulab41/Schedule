# Feedback26：导出筛选变化后重置文件状态

## 目标

导出文件生成后，只要实际改变月份、年份、月份/年份模式、岗位、人员、文件格式或导出类型，旧文件立即失效，页面回到“选择内容后创建任务”，用户必须重新生成。

## 最小设计

- 保留现有导出状态机、请求、轮询、下载和分享流程。
- 所有导出参数变化统一进入现有 `setSelection` 边界；该边界复用 `invalidateExport` 清理任务 ID、等待、迟到回调和临时文件，再一次性提交新的筛选值与 `idle` 状态。
- 岗位和人员多选不新增状态层，继续使用现有 `toggleMultiSelection`，仅把最终 patch 交给统一边界。
- 相同周期模式、格式或导出类型不算切换，不重置现有文件。

## 验证

表驱动回归覆盖月份、年份、周期模式、岗位、人员、格式和导出类型七类变化，断言旧任务和临时文件被清除、文件名为空、状态回到 `idle`，并运行相邻导出 Page/下载边界及 Mini production verify。
