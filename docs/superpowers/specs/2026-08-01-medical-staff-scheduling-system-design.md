# 医护排班 Web 1.0 设计规格（精简版）

## 产品范围

医生排班 Web：账号与群组、成员/角色/班种、自动和手动排班、请假重排、换班、加扣班、事件追踪、统计、通知、导出、PWA 和运维。护士复杂排班另行设计。

## 技术边界

- Web：Vue 3、TypeScript、Vite、TDesign Vue Next、PWA。
- API：Fastify、Zod、MySQL、Drizzle ORM。
- 共享包只放契约、领域逻辑和设计令牌，不依赖 Vue 或 DOM。
- 部署：阿里云 ECS、Docker Compose、Nginx、Fastify、MySQL；正式入口使用备案 HTTPS 域名。

## 核心数据与规则

- 群组隔离用户、成员、联系方式、角色、班种、排班和事件。
- 排班期间有月份、版本和发布状态；发布版本不可被旧写入覆盖。
- 同一班次只有一个当前实际人员；请假、换班和加扣班必须通过事务和版本保护。
- 事件不可变，记录业务变化和必要的操作者信息；统计从排班和事件重算。
- 联系方式仅在所属群组和业务需要范围内显示；导出默认不含手机号。

## Web 体验

- 登录后进入当前群组和当前月份日历。
- 日历支持月/周/列表、节假日、变更标记、筛选、详情和联系方式操作。
- 管理员可从规则或手动模板建立排班，预览冲突后发布。
- 离线仅查看缓存，不允许提交任何业务变更。

## 安全与验收

- 每个接口校验身份、群组、角色、输入、版本和幂等语义。
- 失败不泄露其他群组数据；敏感信息不进入日志和导出。
- 通过单元、集成、并发、安全、性能、Web build 和浏览器 smoke 后才可发布。
