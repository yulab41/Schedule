# 管理员创建账号与 Web 登录设计

- 状态：已实施。
- 范围：Web 登录、会话恢复、退出和资料补全；不提供公开注册。

## 规则

- 账号由授权管理员预置；业务库只保存稳定 UID 和业务资料，不保存明文密码。
- 登录成功后复用同一业务 UID、群组和排班数据。
- 开发认证只在开发环境启用；生产环境缺少正式认证配置时必须启动失败。
- 401 清理会话并引导重新登录；未提交的非敏感表单内容可按页面规则保留。

## 安全边界

- API 校验身份、群组成员关系、角色和版本。
- 日志不记录密码、令牌或完整手机号。
- 认证、会话和权限变化必须有单测、集成测试和浏览器 smoke 覆盖。
