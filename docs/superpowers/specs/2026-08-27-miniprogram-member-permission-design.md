- 日期：2026-08-27
- 生产运行基线：`.51@99006ba`
- 状态：已获用户书面批准，等待重叠并行批次 checkpoint 后实施
- 范围：微信小程序及 `@schedule/client-core` 的小程序接线

## 目标与边界

本轮统一小程序“更多”和群组管理页的角色可见性。普通成员只看到实际可用的入口，不能通过灰色按钮或直接调用控制器触发管理操作，同时保留退出群组、个人日历偏好和手机号公开设置。

不修改 Web、服务端路由、数据库或现有服务端权限。创建/加入群组的限制仅作用于小程序 UI 与控制器；共享 API 行为保持不变。底部五项导航结构不变。

## 集中权限矩阵

工作台使用一个纯函数，根据当前 `GroupSummary` 和客户端 capability 快照生成工具可见性。WXML 渲染与点击处理器使用同一结果。

| 工具                         | 普通成员 | 群主/管理员 | 后台管理员 | capability         |
| ---------------------------- | -------- | ----------- | ---------- | ------------------ |
| 群组管理                     | 显示     | 显示        | 显示       | `core`             |
| 请假、加扣班                 | 显示     | 显示        | 显示       | `workflows`        |
| 事件与统计、通知中心         | 显示     | 显示        | 显示       | `insights`         |
| 通知设置                     | 显示     | 显示        | 显示       | `externalMessages` |
| 手动排班、排班补录、排班配置 | 隐藏     | 显示        | 显示       | `core`             |
| 导出排班                     | 隐藏     | 显示        | 显示       | `insights`         |
| 邀请与访客                   | 隐藏     | 显示        | 显示       | `organization`     |
| 访客访问                     | 隐藏     | 显示        | 显示       | `insights`         |
| 平台账号                     | 隐藏     | 隐藏        | 显示       | `organization`     |

角色或 capability 不满足时，入口及空分组不进入 WXML/无障碍树，不显示伪可用的 disabled 按钮。点击处理器仍重复检查同一矩阵，防止旧状态或程序调用绕过。访客没有可用工具时显示只读空状态。

## 群组管理页

- 普通成员可查看当前群组名称、角色、群组码、成员，以及服务端允许显示的联系方式。
- 普通成员不显示群组资料修改、解散/恢复、创建/加入、成员编辑、认领、角色或预设名单操作；对应控制器方法也直接拒绝。
- 普通成员继续显示“退出群组”和“我的手机号公开设置”。
- 群主独占群组资料、解散/恢复；群主、管理员和后台管理员可以创建/加入群组并管理成员；后台管理员沿用现有服务端例外。
- 无创建/加入权限的角色不请求群组目录或已解散群组数据。

## 日历偏好

新增严格的 `CalendarPreferencesClient`，复用现有契约与端点：

- `GET /groups/:groupId/calendar-preferences`
- `PUT /groups/:groupId/calendar-settings`
- `PUT /groups/:groupId/calendar-preferences/mine`

客户端使用 `core` capability、Bearer 与严格响应解码，不缓存、不持久化草稿、不建立离线写队列。群组页从既有排班配置只读接口取得启用班种。

所有非访客都可设置个人默认视图（跟随群组/月/周/列表）与月视图默认班种。服务端返回 `canManageGroupDefaults=true` 时，额外显示群组默认视图和班种。`null` 继续表示跟随群组或自动选择。

偏好读取与群组基础资料分开结算：偏好失败只显示卡片内错误和重试，不使联系方式或成员列表失败。保存期间按钮显示忙碌并防止重复提交；失败保留当前草稿，成功以响应整体替换偏好状态。

## 验收

- 普通成员“更多”精确保留群组管理、请假、加扣班、事件与统计、通知设置、通知中心。
- 所有权限隐藏同时具备控制器守卫；管理员和后台管理员矩阵与真实 API 权限一致。
- 普通成员群组页为只读群组资料 + 两项个人设置 + 退出群组。
- 个人和群组日历偏好均能读取、保存、失败重试，并保持 `null` 语义。
- Web、API、数据库和底部导航无行为变化。
