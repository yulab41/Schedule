# Feedback24 导出选择器与匿名访客日历等价设计

## 范围

- 导出页岗位、成员和文件类型统一复用现有 `ui-selector`；修复宿主卡片裁剪，不修改共享选择器。
- 匿名访客护士日历补齐成员当前使用的护士预设、群组默认月历班种、状态、折叠和周滑动提交机制。
- 成员日历页面、成员API和现有访客月历响应保持不变。

## 设计

导出表单卡片允许选择器弹层越过卡片内容区显示。文件类型使用 `ui-selector` 单选模式，继续调用现有 `handleTypeChange`，避免第二套选择器状态。

新增独立匿名访客显示设置端点，使用访客密钥和现有公开访客能力守卫，只返回群组ID、群组默认视图及群组默认月历班种ID。不能向旧访客月历响应增加字段，因为严格客户端会把新增字段判为无效资料。访客首次进入采用群组默认视图（护士群当前为周、医生群当前为月），重新显示时刷新设置；若用户本次会话没有主动偏离旧默认，群组设置变化会同步应用。访客ViewModel在护士群传入 `nursePreset`，并在显示设置完成前隐藏月历班种，避免先按错误规则渲染。

访客周/列表swiper采用成员已验证的单提交状态机：动画结束只提交一次，0ms归中，提交期间锁定，连续操作进入有界队列。按钮和手势共用同一路径。

持久公开缓存仅在网络失败时作为回退；成功网络路径不先显示持久缓存。当前页面内已确认的月份仍可即时复用，相邻窗口扩大到前后两个月，减少快速切换缺页。

## 验证

- 旧代码失败回归覆盖卡片裁剪、原生文件类型picker、护士显示选项、0ms归中/重复finish、持久缓存闪现。
- 运行guest runtime、selector、export controller、上传转换、Mini build/typecheck/lint/Worklet/包体和完整门禁。
- 自动化不代替小米14对手势、弹层和快速切月的验收。
