# 头颈外科医生群 DOCX 排班导出设计

## 目标与范围

仅为头颈外科医生群提供 DOCX 排班导出。该群的排班导出以用户最终调整的 Word 文件为视觉权威；其他群组不显示也不能请求 DOCX。统计数据不支持 DOCX，继续使用既有 Excel 或 CSV 导出。

月度导出生成一个单页 DOCX。年度导出生成一个 DOCX，按一月至十二月固定十二页，每月强制从新页开始。小程序只负责选择、创建任务、登录态下载和用户主动发送；服务端拥有数据选择、权限校验和 DOCX 生成。

## 视觉权威与精确参数

用户最终文件位于 ignored runtime，SHA-256 为 `AAC675F7156354903370FFA32193436C792418CDD00A469BD1D5AFEE1E76B593`。该文件含真实姓名，不进入 Git；实现使用无真实姓名的合成黄金夹具保存相同结构和度量。

页面与段落参数：

- A4 纵向，21.001 cm × 29.7 cm。
- 页边距：上 1.799 cm、下 1.6 cm、左 2.799 cm、右 2.401 cm。
- 标题为 `YYYY 头颈值班 MM 月`，Word Title 样式、黑色、24 pt、居中，段前 10 pt、段后 8 pt，不带边框或装饰线。
- `一值`标题为 22 pt，段后 2 pt。
- 正文字体的中文东亚字体为宋体，数字为 Times New Roman；所有颜色为黑色。

上部排班表：

- 无可见边框，人员和日期均垂直居中。
- 每个人员一行，行高延续黄金文件的固定度量。
- 姓名列宽 3.477 cm；五个日期列宽依次为 1.753、1.755、1.755、1.755、1.755 cm。
- 姓名左对齐，22 pt；日期居中，16 pt。
- 周六、周日日期加单下划线，工作日不加下划线。
- 一值人员按该月实际值班记录的首次出现顺序列出；每人日期按升序排列。计划人员不替代实际人员。

底部一值与二值表：

- 无可见边框，两行八列。
- 标签列宽 1.799 cm；后七列均为 1.951 cm。
- 标签左对齐，人员居中；字号 14 pt。
- 一值只列该月实际一值人员；二值通过部署期按成员 ID 配置的映射逐人取得，不把真实姓名或成员 ID 写入 Git。
- 未使用的尾列保持空白，不自动拉伸或重新均分。

三值表：

- 与一值/二值表分离，保持黄金文件现有垂直间隔。
- 无可见边框，一行四列，列宽依次为 1.501、3.498、2.499、7.95 cm。
- `三值`左对齐；两名固定三值人员分别在第二、第三列居中；字号 20 pt。
- 固定人员通过部署期成员 ID 配置注入，不在源码中保存姓名。

生成器必须保留黄金文件当前的空白段落、表格顺序和分页属性；不得使用自动适应列宽或由内容重新分布列。

## 接口与权限

在既有 `csv | xlsx` 格式上增加 `docx`。服务端在创建任务前同时验证：

1. `exportType` 必须为 `schedule`；`statistics + docx` 返回明确的 400 校验错误，不创建任务。
2. 群组 ID 必须位于服务端头颈 DOCX 配置中；其他群组的 DOCX 请求返回明确的 403/能力不可用错误，不创建任务。
3. 二值映射与两名固定三值配置必须完整且全部属于目标群组；配置缺失时返回可操作错误，不生成部分或错配文件。

目标群组的排班格式选择由 Excel 改为 Word；CSV 保持兼容。统计选择时 Word 选项隐藏或禁用，并自动回到 Excel，避免提交无效组合。其他群组不渲染 Word 选项。服务端校验是最终权限边界，客户端隐藏不能替代它。

下载响应使用 `.docx` 文件名和 `application/vnd.openxmlformats-officedocument.wordprocessingml.document`。Bearer 请求头、无 URL token、临时文件清理、主动发送和取消语义保持不变。

## 数据与分页

月度生成器只读取已授权群组和请求月份的数据，按实际成员聚合。一年请求按十二个月分别查询和渲染；每个月都复用同一个固定页面布局并插入硬分页。即使某个月没有排班，也保留该月页面、标题和固定三值区域，一值/二值区域为空，不借用相邻月份空间。

年度文件必须恰好十二页。每页只含对应月份数据，不跨月合并日期或人员。

## 验证

- 生成器单元测试：OOXML 包结构、MIME、文件名、A4 页面、边距、字体、字号、列宽、对齐、周末下划线、无边框和硬分页。
- 数据测试：实际人员优先、换班后的实际成员归组、日期排序、二值按成员 ID 匹配、固定三值、空月。
- API 集成测试：目标群月/年 DOCX、非目标群拒绝、统计 DOCX 拒绝、配置不完整拒绝、旧 CSV/Excel 兼容。
- 小程序回归：目标群排班显示 Word；统计不显示 Word且不会提交 DOCX；其他群无 Word；下载与发送继续使用原登录态流程。
- 视觉黄金测试：以同一份合成 9 月数据生成 DOCX，在可用的 Microsoft Word 渲染环境中逐页与去标识化黄金文件比较。页面数、关键几何和像素差异不满足门槛时不得交付。
- 年度视觉测试检查全部十二页，不以首页抽检替代。

自动化和 Word 渲染不能代替小米 14 打开同一候选文件的原生验收。体验上传、生产部署、目标群生产配置和正式发布均需各自的当前消息授权。

## 明确不做

- 不为其他群组开放 DOCX。
- 不为统计生成 DOCX。
- 不在小程序端拼装 OOXML。
- 不提交含真实姓名、成员 ID 或生产数据的模板、截图或测试夹具。
- 不改变现有权限、审计、下载鉴权、临时文件生命周期或 CSV 兼容行为。
