# 头颈外科医生群 Word 排班导出配置

此功能默认关闭。服务器仅在 `HEAD_NECK_DOCX_EXPORT_CONFIG` 为合法完整 JSON 时，为其中唯一的群组开放 Word 排班导出。

配置结构如下，所有值均使用生产数据库中的稳定 UUID，不使用姓名：

```json
{
  "groupId": "00000000-0000-4000-8000-000000000000",
  "firstDutyRoleId": "00000000-0000-4000-8000-000000000000",
  "firstDutyMembershipIds": ["00000000-0000-4000-8000-000000000000"],
  "secondDutyNameByFirstMembershipId": {
    "00000000-0000-4000-8000-000000000000": "固定二值姓名"
  },
  "thirdDutyNames": ["固定三值姓名一", "固定三值姓名二"]
}
```

启用前必须只读核对：目标群组、目标一值岗位和全部一值成员均为当前有效成员；每名一值必须有非空的固定二值显示姓名，两名固定三值显示姓名也必须非空。二值和三值文本只用于头颈值班表排版，不创建、恢复或授权成员。配置缺失、JSON错误、映射缺项、一值成员失效或跨群时，服务端拒绝创建 Word 任务，不生成部分文件。

生产启用需要当前消息明确授权，并与 schema60 部署一起执行。部署后验证目标群排班选项为 Word/CSV、统计为 Excel/CSV；其他群仍为 Excel/CSV。不得把生产 UUID、姓名或导出文件写入 Git、日志或审计截图。
