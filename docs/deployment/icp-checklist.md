# ICP 备案检查清单

> 状态：**未开始**。2026-08-07 用户决定先以阿里云 ECS 试用部署，域名与 ICP 备案延后。
> 本清单供预算到位后按序执行。

## 前置条件

- [ ] 现有域名已完成实名认证，且符合中国大陆备案要求。
- [ ] 已购买满足备案条件的阿里云（或其它大陆服务商）资源（备案要求以服务商最新文档为准）。
- [ ] 备案主体信息（个人或企业）齐全：身份证/营业执照、联系方式、网站名称、服务内容等。
- [ ] 确认是否需要接入备案（已备案域名但服务商变更时）。

## 备案步骤

1. **确认域名实名认证与备案主体**：域名所有者信息与备案主体一致。
2. **购买备案云资源**：按服务商「备案云资源要求」购买满足条件的资源并获取备案服务码。
3. **提交 ICP 首次备案或接入备案**：在服务商备案系统填写主体与网站信息、上传核验材料、完成人脸核验与管局审核。
4. **备案通过后绑定域名**：DNS A 记录指向 ECS 公网 IP，配置 HTTPS（见 `docs/deployment/dns-and-https.md`）。
5. **公安联网备案**：上线后按适用要求在全国互联网安全管理服务平台办理公安联网备案，并放置备案号链接（适用时）。

## 需要准备的材料

- 域名实名认证截图/证明。
- 个人：身份证正反面；企业：营业执照、法人身份证、网站负责人身份证。
- 手机号与应急联系方式（需能接收核验短信/电话）。
- 网站名称与前置审批材料（如网站涉及医疗相关内容，需按属地管局要求确认是否需前置审批或调整名称）。
