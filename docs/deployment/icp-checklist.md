# ICP 备案简表

本文件只记录 Web 正式公网访问的备案前置，不替代阿里云控制台流程。

## 提交前

- 阿里云账号、域名和主体完成实名认证。
- ECS 为中国大陆节点，已获得备案服务码并保持运行。
- 准备主体证件、负责人手机号、应急联系人和网站负责人信息。
- 确认主域名备案覆盖 Web 子域名，站点名称、内容和负责人信息一致。

## 提交后

1. 通过阿里云 ICP 系统提交。
2. 审核期间保留可用的开发入口，不宣称正式上线。
3. 备案通过后绑定域名、启用 HTTPS、验证 `/api/health` 和 Web smoke。
4. 将备案号、域名、证书和负责人变更记录在生产配置中。
