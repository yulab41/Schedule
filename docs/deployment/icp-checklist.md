> 状态（2026-08-08 已确认）：beian.miit.gov.cn 按“网站”类型查询 `eylinhome.top` 无数据；阿里云“我的 ICP 备案信息”显示暂无备案主体信息 → **没有已有备案**，需走**首次备案（个人）**，主办者 = 用户本人。
> 当前 ECS `120.77.220.79`（i-wz98vjgval1ptp4e8hb0）满足备案条件：包年包月（99 元/年，>3 个月）、中国大陆节点、有公网带宽（3 Mbps）；每台 ECS 可免费生成 5 个备案服务码。
> 子域名 `hosp.schedule.eylinhome.top` 会被主域名 `eylinhome.top` 的备案自动覆盖，不需要单独备案。

## 一、操作前自查（全部满足再提交）

- [ ] 阿里云账号已完成实名认证，实名信息与本人身份证一致（控制台右上角账号头像 → 账号管理查看）。
- [ ] 域名 `eylinhome.top` 已完成域名实名认证，且**域名持有者姓名/证件号码与本人身份证一致**。检查入口：域名控制台 → 域名列表 → 管理 → 域名信息。若不一致，先做域名信息修改/过户并等待生效，再提交备案。
- [ ] ECS 计费方式为**包年包月**（当前 99 元/年即满足），且实例处于运行中、有公网 IP。
- [ ] 本人手机号能接收短信；另准备一个**应急联系电话**（建议家人的号码；若系统提示不能与负责人手机号相同，必须更换）。
- [ ] 身份证原件在手，准备好清晰的正反面照片（JPG/PNG，可加水印“仅供阿里云备案使用”，但不能遮挡证件信息）。
- [ ] 准备常住地址（精确到门牌号，按管局要求一般填身份证地址或现居住地址）。
- [ ] 想好网站名称：至少 3 个汉字，不含“博客/论坛/平台/社区/个人空间/作品展示/网络/网址”等禁用词，不用纯数字、纯英文、特殊符号，不用人物名/地名/成语，且与实际内容一致。示例：“个人排班助手”（最终以审核为准）。
- [ ] 内容定性：备案性质选“个人”，服务内容选“其他”，备注写“个人开发使用的排班管理工具，非经营性，无医疗问诊、在线支付、新闻信息服务”。页面不要展示企业/单位信息；若系统会公开提供医疗机构相关服务，个人备案可能不适用，需先评估是否改单位备案。

## 二、提交步骤（阿里云 ICP 备案系统）

1. 打开 <https://beian.aliyun.com/>（或用阿里云 App 搜“ICP备案”），登录本人实名账号。
2. 点击“开始备案”。基础信息校验：选择地区（身份证/常住地所属省）、备案性质“个人”、证件类型“身份证”，填写姓名、证件号码和域名 `eylinhome.top`，点击校验。
3. 填写**主体信息**：姓名、身份证号、证件有效期、证件住所/常住地址、负责人手机号、应急联系电话、邮箱等。
4. 填写**网站信息**：网站名称、域名（系统自动带出）、服务内容选“其他”、网站语言“简体中文”、网站备注。前置审批：不需要（网站不涉及新闻、出版、药品、医疗器械等）。
5. 填写**服务器信息**：选择账号下的 ECS `120.77.220.79`（搜实例 ID：`i-wz98vjgval1ptp4e8hb0`），系统自动带出或手动填入备案服务码。找不到服务码时，到 ICP 备案系统“服务码管理”页生成（每台 ECS 最多 5 个免费服务码，每个只能用一次）。
6. 上传**资料并核验**：身份证正反面照片 → 手机短信链接完成信息核验 → 按提示完成人脸核验（阿里云 App）。
7. 确认主体与网站信息无误，提交初审。

## 三、审核时间线

- 阿里云初审：约 1～2 个工作日（可能来电核验，注意接听；缺材料会通知补充）。
- 初审通过后约 5 分钟收到工信部短信 → 需在 **24 小时内**到 beian.miit.gov.cn 完成“短信核验”。
- 管局审核：最长约 20 个工作日（多数情况几天到 2 周）。全程约 3～22 个工作日。
- 备案订单有效期 45 天，超时会被自动删除，需重新提交。

## 四、备案期间网站访问（需要用户决策）

首次备案的新域名，在管局审核通过前**不得对公众开放访问**，否则有备案驳回风险（阿里云官方答复，见参考链接）。三个可选方案：

- **方案 A（推荐）**：域名页面临时换成“网站备案中”提示页，公网 IP 访问也关闭；备案通过后一键恢复正式页面。缺点：备案期间你自己也不能公网访问系统。
- **方案 B**：仅允许你指定的固定公网 IP 访问，其他访问者看到“备案中”页。适合备案期间还想自己使用的情况。
- **方案 C（不推荐）**：保持现状公开访问，可能被管局/阿里云检测到导致驳回。

已实施（2026-08-08）：用户选定**方案 A**，服务器已开启备案维护模式：

- 开启：`bash infra/scripts/icp-maintenance.sh on`（服务器路径 `/opt/schedule/infra/scripts/icp-maintenance.sh`）
- 恢复：`bash infra/scripts/icp-maintenance.sh off`（备案通过后执行）
- 效果：域名与公网 IP 均只显示“网站备案中”占位页；公网 IP 的 HTTPS 直接断开；阿里云对未备案域名本身还会返回拦截页（HTTP 403 `Non-compliance ICP Filing`），外部访问已被双重关闭。
- 验证：服务器本地 `curl` 域名 HTTPS 200 → `/icp-placeholder.html`（正文含“网站备案中”）；`/.well-known/acme-challenge/` 带正确 Host 返回 404（入口保留，证书续期不受影响）。

**备案期间如何自测真实系统**（2026-08-08 新增）：

1. 双击仓库里的 `scripts/start-ecs-test-tunnel.bat`（效果等同手动执行 `ssh -i "%USERPROFILE%\.ssh\aliyun_schedule" -N -L 8080:127.0.0.1:8080 root@120.77.220.79`），保持黑色窗口开着。
2. 浏览器打开 `http://localhost:8080`，即可看到真实系统（本地管理员/本地成员可正常登录测试）。
3. 测试完关闭窗口即断开。该入口在服务器上只绑定回环地址（127.0.0.1:8080），公网无法访问，不影响备案。

> 说明：批处理文件为避免 Windows 中文编码问题，窗口提示为英文（`Connecting to server test tunnel...` 等），属正常现象；连接成功后浏览器直接访问 `http://localhost:8080` 即可。

## 六、常见疑问（2026-08-08 确认）

1. **网站名称填什么？域名那栏填什么？**
   网站名称是给人看的中文名字，不是域名；域名那栏填主域名 `eylinhome.top`（不带 www、不带子域名）。官方禁止用域名、纯数字、纯英文、特殊符号作为网站名称，所以“个人排班助手”这样的中文名是正确的，和域名栏是两回事。
2. **以后同一个域名下加子域名/新页面，需要重新备案吗？**
   不需要。主域名备案成功后，覆盖其下所有子域名（如 `tools.eylinhome.top`），无需单独备案。但若新内容与备案申报的性质差异过大（例如从个人工具变成经营性、新闻、医疗问诊等），可能需要办理变更备案，届时按管局要求处理。
3. **以后用了新域名（如 `anotherdomain.top`），需要重新备案吗？**
   不需要从零重备。同一备案主体（同一个人）下新增域名走“新增网站/新增域名”备案，主体材料不用重新提交，比首次备案简单。只有主体性质变化（如个人变企业）才需要注销原备案后重新备案。
