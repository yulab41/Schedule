## 4. 升级到正式环境的执行清单

1. 完成自建/微信账号认证（后端用户表扩展 + 登录接口 + 前端表单），移除本地开发认证依赖。
2. 购买域名并完成 ICP 备案（见 `docs/deployment/icp-checklist.md`），按 `docs/deployment/dns-and-https.md` 接入 HTTPS。
3. 迁移到正式 MySQL（独立实例或 RDS），创建最小权限运行账号（`schedule_runtime` 类）；`schedule_events`/`audit_logs` 仅 `SELECT`/`INSERT`。
4. 收敛 ECS 安全组与网络暴露；生产密钥与开发密钥完全分离。
5. 配置定时任务（通知重试、值班提醒、备份、群组回收、统计重建、节假日提醒）与持久化备份存储。
6. 配置监控与费用告警（见 `docs/operations/monitoring.md`）。
7. 正式环境验收通过后下线试用入口，并更新 `docs/project-status.md`。

## 5. 已知风险与待办

- 腾讯云 CAM SecretId/SecretKey 曾在早期对话中暴露：CloudBase 已弃用，若腾讯云账号仍保留需轮换并删除相关 GitHub Secrets（`TENCENT_SECRET_ID`/`TENCENT_SECRET_KEY`、`CLOUDBASE_*` 变量）。
- `schedule_app` 单账号管理级授权 + 公网暴露是当前最大安全敞口；升级第 3 步必须收回。
- 定时任务缺失会使提醒/重试/备份长期不运行；升级第 5 步前按需手动执行 `node apps/api/dist/run-job.js --job=...`。
- 当前试用机仅 1.6G 内存，正式化建议更换实例规格或拆分服务。
