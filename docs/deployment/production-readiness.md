## 4. 升级到正式环境的执行清单（预算到位后）

1. 购买满足备案条件的域名与腾讯云资源，按 `docs/deployment/icp-checklist.md` 完成 ICP 备案。
2. 按 `docs/deployment/dns-and-https.md` 绑定自定义域名、CNAME、HTTPS 证书，并更新 Web 安全域名与部署健康检查变量。
3. 创建独立正式 CloudBase 环境与正式 MySQL；云函数启用 VPC 内网连接。
4. 创建最小权限运行账号（`schedule_runtime` 类），`schedule_events`/`audit_logs` 仅 `SELECT`/`INSERT`；生产密钥与开发密钥完全分离。
5. 接入 CloudBase 云存储备份适配器（`cloudPath`/`fileID` 语义需在真实环境验证），备份文件离开函数临时盘。
6. 按 `docs/operations/monitoring.md` 配置调用量、流量、资源点与费用 70%/85%/100% 告警，以及证书、备份、定时任务告警。
7. 上线后按适用要求办理公安联网备案。
8. 完成正式环境验收后，把默认测试域名从正式入口下线。
