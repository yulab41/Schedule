# Web 1.0 验收摘要

## 范围

账号、群组、成员、角色、班种、自动/手动排班、请假、换班、加扣班、日历、事件、通知、统计、导出、PWA、备份和部署。

## 核心验收

- 登录后直接看到当前月份值班人员。
- 管理员可建立、预览、发布和维护排班；并发修改有版本保护。
- 日历支持月/周/列表、节假日、变更标记和联系方式操作。
- 工作流、事件和统计结果可追溯；导出不含手机号。
- 跨群组数据隔离，离线只读不写入。
- Web build、全量测试、安全检查和浏览器 smoke 全部通过。

## 正式发布

备份 → 开发环境完整验收 → 明确批准 → ECS 部署/迁移 → 生产 smoke → 创建版本标签。失败保留上一可用版本。
