# 发布制品权限

Windows打包可能携带文件0666/目录0777，root普通解包会保留。2026-11-06实测AI账户可写网关和目录，且发布归档及API/Web/迁移/依赖树均有宽写权限。环境凭据和Docker socket访问均被拒绝。

机制来源为07c60456的普通root解包和18b5fe1f的平铺ZStd解包，首次实际暴露时间尚未追溯。本轮数据见shared-gateway-isolation-20261105报告。

- 所有部署/恢复写解包都使用umask022及no-same-permissions/no-same-owner。
- 固定受管代码树、父目录和文件保持root所有、去除group/other写权限并保留执行位。覆盖解包前后和恢复路径，排除业务数据及AI独立工作目录。
- 当前八组发布树确认无符号链接，发布权限规则拒绝树根、嵌套和项目根符号链接。开发工作树依赖链接不属于此规则范围。
- 生产校验同时验证字节哈希和权限，文件哈希一致不能替代写边界检查。
- Linux合成夹具验证不安全解包、644/755、执行位、内外链接和根链接拒绝，并检查外部夹具未改动。部署后以实际AI账户再次确认不可写网关及目录。

守卫为infra/scripts/artifact-permissions.spec.ts和真实Linux权限夹具。依赖布局、归档格式、受管路径或链接规则变化时，重新调查并验证，禁止仅放宽守卫。
